# Three alternative looks — brief for the build agents

Goal: three homepage designs for TonyAI that look **nothing like each other and nothing like the current site** (which is light, grey-green, Schibsted Grotesk, white cards). Same copy, same demo data, same sections. Awwwards-calibre: a strong single idea, confident type, deliberate motion, no template feel, no stock-SaaS card grid.

## Ground rules (all looks)

- Route: `app/tasarim/<letter>/page.tsx` (letters a, b, c). Components in `components/looks/<letter>/`. One CSS file `components/looks/<letter>/look.css`, imported by the page, **everything scoped under `.look-<letter>`** so it cannot leak into the live site. Set the look's own background on the wrapper (`min-height:100vh`), not on `body`.
- Do **not** edit anything outside your folders except the one-line addition of your route to `docs/qa/fullpage.py` PAGES is NOT needed — write your own screenshot script in your folder instead.
- Copy: import everything from `@/content/copy` (`copy`, `demo`). Do not rewrite sentences; you may choose which fields to show, shorten lists, split the title across lines, set one word in italic/accent. Sections to cover in this order: nav, hero (with the six-subsidiary → consolidated-total idea in some form), standards strip, "TonyAI farkı" (5 cards, card 5 carries `copy.difference.wipTag` because `wip: true`), platform (4 modules), demo (video placeholder + CTA), journey (6 steps), compliance (standards + audit + security), roadmap (3 items incl. 2027), proof (illustrative case, keep the disclaimer), FAQ (6), final CTA, footer. Primary CTA everywhere: `copy.hero.primary` → `/demo/`.
- Logo: reuse `components/Logo.tsx` (`Logo`, `Mark`) but you may recolour via `currentColor`.
- Fonts: self-hosted via fontsource packages already installed in node_modules — import the CSS in your page, e.g. `import "@fontsource-variable/fraunces/wght.css"` (check each package's folder for the exact css file names: `ls node_modules/@fontsource-variable/<name>`). Available: fraunces, instrument-serif (static), space-grotesk, bricolage-grotesque, jetbrains-mono, syne, archivo, inter-tight, dm-sans. Use at most two families.
- Motion: GSAP + ScrollTrigger + Lenis are installed; load them with dynamic `import()` after mount inside a `"use client"` component as the live site does (see `components/Hero.tsx`, `components/SmoothScroll.tsx`). No scroll-jacking (never capture or snap the wheel; pin + scrub is fine). Everything must be static and readable under `prefers-reduced-motion`.
- Accessibility and QA floor: one `h1`, semantic landmarks, WCAG AA contrast, 44×44 px targets on mobile, no horizontal scroll at 390 px, Lighthouse mobile performance ≥ 85 (check with `CHROME_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npx lighthouse http://localhost:<port>/tasarim/<letter>/ --preset=... --only-categories=performance,accessibility --form-factor=mobile --screenEmulation.mobile --quiet --chrome-flags="--headless --no-sandbox" --output=json --output-path=...`).
- Next.js 16 App Router, static export. Read `AGENTS.md` and `node_modules/next/dist/docs/` if an API surprises you. Global CSS import from a page is allowed in the App Router.
- Verify: `npm run build`, then `npx serve out -l <port>` and a Playwright script (python, `from playwright.async_api import async_playwright`, chromium is preinstalled; do not run `playwright install`) that screenshots your route full-page at 1440 and 390, scrolling through first so reveals fire. Save screenshots to `components/looks/<letter>/qa/`. Look at them (Read the PNG) and fix what is wrong before finishing. Iterate at least twice.
- Finish by writing `components/looks/<letter>/NOTES.md`: the idea in three sentences, type and colour choices, motion, what you would do next, and honest self-critique.

## Look A — "Kömür" (dark editorial)

Near-black charcoal (`#0e0f0e`-ish, never pure black) with a warm off-white text and one luminous accent (a phosphor green around `#9df0b0`, used sparingly for data and the CTA). Display type: **Fraunces** variable (opsz high, soft/wonk off) at very large sizes with tight leading, italic for one emphasised word; body **Inter Tight**. Mono numbers in **JetBrains Mono**. Feel: a cinematic annual-report-meets-observatory. Hero: the six subsidiary values rendered as thin glowing horizontal bars or a constellation that converges into the 164.700 total as you scroll (pin + scrub on desktop, autoplay once on mobile). Fine 1px hairlines, subtle film grain (CSS noise via SVG feTurbulence at low opacity, static), big section numerals (01–08) in the margin. Generous dark space; cards replaced by rule-separated rows. Footer as a giant wordmark.

## Look B — "Defter" (Swiss brutalist ledger)

Paper white `#fafaf7`, ink black, and one acid accent (chartreuse `#d4ff3a` or safety orange `#ff5a1f`, pick one and own it). Type: **Archivo** variable at extreme weights (Expanded/Black for headlines via `font-stretch` and weight 800–900) with **JetBrains Mono** for everything tabular; all-caps mono labels with letterspacing. A visible 12-column grid: hairline rules everywhere, exposed column lines, numbered sections, oversized numerals (e.g. the "3 / 11 / 1" strip as 200px figures). Hero is typographic: the headline fills the width, with the subsidiary ledger shown as an actual table (monospace, right-aligned numbers) that gets a final "Konsolide toplam" row drawn in with a sweeping underline as you scroll. Marquee strip of standards. No rounded corners, no shadows, square buttons with thick borders, hover inverts to black. Brutal but impeccably aligned.

## Look C — "Atmosfer" (soft, warm, organic)

Warm sand/cream `#f6f1e8` base, deep moss `#1f3d2b` and terracotta `#c96a3d` accents, soft radial gradients and blurred colour fields (CSS only, no images) that drift slowly. Type: **Bricolage Grotesque** variable for display (wide opsz, playful but serious), **DM Sans** for body. Everything rounded (24–32px), tactile pill chips, big friendly numerals, generous air, illustrative data: the six subsidiaries as soft-coloured circles sized by value that gather into one big circle (the consolidated total) on scroll; the scopes as a stacked, rounded bar. Sections alternate cream / moss-dark bands. Consumer-tech warmth for an enterprise product. Buttons pill-shaped with a subtle inner glow on hover. Avoid any "SaaS template" feel: asymmetric layouts, one oversized element per section, photography-free.
